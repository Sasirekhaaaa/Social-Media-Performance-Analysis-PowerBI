# Social Media Performance Analysis using power BI
## Project Objective
To analyze social media performance across different platforms, regions, and content types using Power BI, identify engagement trends, and provide interactive insights to support data-driven decision-making.
## Tools And Technologies
- Microsoft Power BI
- DAX
- Data Visualization
- Data Cleaning
- CSV Dataset
## Dataset
The dataset contains social media post-level information including:
- Post ID
- Platform
- Region
- Content Type
- Post Date
- Likes
- Comments
- Shares
- Reach
## Key DAX Measures
Created DAX measures for:
- Total Likes
- Total Comments
- Total Shares
- Total Reach
- Average Likes Per Post
- Average Comments Per Post
- Engagement Score
- Average Engagement per Platform
- Maximum Reach
- Minimum Reach
- Posts Count
- Instagram Engagement
- Video Content Engagement
- Region-wise Reach
## Calculated Columns
Created calculated columns for:
- Engagement
- Engagement Level
- Post Year
- Post Month
- Post Day
- Reach Category
- Platform Code
## Dashboard Features
The interactive dashboard includes:
- KPI Cards
- Engagement by Platform
- Reach by Region
- Content Type Performance
- Monthly Engagement Trend
- Top 5 Posts by Engagement
- Engagement Level Analysis
## Interactive Slicers
- Platform
- Region
- Content Type
- Post Date
## Key Insights
- Identified the highest-performing social media platforms.
- Compared engagement across different regions.
- Analyzed which content types generate higher engagement.
- Identified the top 5 posts based on engagement.
- Analyzed monthly engagement trends.
- Compared social media reach across regions.
## Questions (KPIs)
- Which platform has the highest engagement?
- Which region has the highest reach?
- Which content type performs best?
- What is the monthly engagement trend?
- Which are the Top 5 posts by engagement?
- Which platform has the highest average engagement?
- What are the high, medium, and low engagement posts?
- How does social media performance vary across platforms and regions?
